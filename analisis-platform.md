# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Pendahuluan

Platform pengembangan aplikasi merupakan lingkungan yang digunakan untuk membangun dan menjalankan perangkat lunak. Tiga platform yang umum digunakan adalah Web, Desktop, dan Mobile. Ketiganya memiliki karakteristik berbeda dalam bahasa pemrograman, arsitektur, distribusi, keunggulan, keterbatasan, serta jenis aplikasi yang dapat dikembangkan.

## 2. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, serta bahasa sisi server seperti PHP, Python, atau JavaScript dengan Node.js. | C#, Java, C++, Python, dan JavaScript dengan framework desktop. | Kotlin dan Java untuk Android, Swift untuk iOS, serta Dart dengan Flutter atau JavaScript/TypeScript dengan React Native. |
| Arsitektur | Umumnya menggunakan arsitektur client-server. Browser bertindak sebagai client yang berkomunikasi dengan server melalui jaringan. | Aplikasi berjalan pada sistem operasi komputer dan dapat menggunakan arsitektur monolitik, modular, atau client-server. | Aplikasi berjalan pada perangkat seluler dan dapat menggunakan arsitektur native, cross-platform, serta berkomunikasi dengan server melalui API. |
| Cara distribusi | Dipublikasikan pada web server dan diakses melalui browser menggunakan URL. | Umumnya didistribusikan melalui installer, paket aplikasi, atau toko aplikasi sesuai sistem operasi. | Didistribusikan melalui toko aplikasi seperti Google Play Store dan Apple App Store, atau melalui metode instalasi lain yang didukung platform. |
| Keunggulan | Mudah diakses melalui browser, pembaruan dapat dilakukan di server, dan dapat digunakan pada berbagai perangkat yang kompatibel. | Dapat memanfaatkan sumber daya komputer, mendukung integrasi dengan sistem operasi, dan cocok untuk aplikasi produktivitas serta pekerjaan khusus. | Mendukung fitur perangkat seperti kamera, GPS, sensor, notifikasi, dan penggunaan aplikasi saat bepergian. |
| Keterbatasan | Penggunaan fitur perangkat tertentu bergantung pada dukungan browser dan sistem operasi. Aplikasi juga dapat bergantung pada koneksi jaringan untuk fitur yang memerlukan server. | Perlu memperhatikan kompatibilitas sistem operasi dan perangkat keras. Instalasi serta pembaruan biasanya dilakukan pada setiap perangkat. | Memerlukan perhatian terhadap ukuran layar, daya baterai, kapasitas perangkat, perbedaan versi sistem operasi, dan ketentuan distribusi aplikasi. |
| Contoh aplikasi | Gmail versi web, Google Docs, dan aplikasi e-commerce berbasis browser. | Microsoft Word versi desktop, Visual Studio Code, dan aplikasi pengolah gambar desktop. | WhatsApp pada Android/iOS, Google Maps pada perangkat seluler, dan aplikasi mobile banking. |

## 3. Kesimpulan

Platform Web, Desktop, dan Mobile memiliki kelebihan serta keterbatasan masing-masing. Web unggul dalam kemudahan akses dan pembaruan terpusat. Desktop cocok untuk aplikasi yang membutuhkan integrasi dengan sistem operasi dan sumber daya komputer. Mobile lebih sesuai untuk kebutuhan yang memanfaatkan mobilitas serta fitur perangkat seluler. Pemilihan platform perlu disesuaikan dengan kebutuhan pengguna, tujuan aplikasi, perangkat sasaran, dan lingkungan pengembangannya.
